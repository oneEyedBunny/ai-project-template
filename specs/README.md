# Specs

Feature specs live here. This is where spec-kit operates (https://github.com/github/spec-kit).

One folder per feature: `specs/001-feature-name/` containing `spec.md`, `plan.md`,
`tasks.md`. Spec-kit turns intent into the *what*; your `.ai/engineering/` files
constrain the *how*; your `.ai/client/` files ground the *why*. They compose — spec-kit
supplies the specs, the `.ai/` directory supplies the context spec-kit assumes you have.

Non-trivial features start here. If we can't write the spec, we don't understand the
feature well enough to build it yet.
